# Legacy Metal fixes

Every workaround in this folder, grouped by the file it ships in, with the bug it works around, its test and its off switch.
Test ids (`Tests/`): `sNN` MetalOldCompat and AMDBronzeCompat, `aNN` AMD adapter, `cNN` libAMDIL902 patches, `iNN` Intel
adapter, `nNN` Kepler (NVIDIA adapter and the shim's Kepler fixes), `rNN` regression guards. Columns: the fix's item number
in its source file, its tests, the bug, the fix, and the environment variable that turns it off (`=0` unless shown).
`Tests/verify.sh` runs each test without and with its fix.

## 6. Tahoe's compiler for the Metal 3802 stack: 14.2 Beta 1 instead of 13.x

The 13.x front end stops at MSL 3.0, so MSL 3.1 texture atomics (a01) don't compile from source on Tahoe. `tools/make_tahoe_compiler.py` builds the `14.2 Beta 1` compiler the Sequoia patches use, moved from `Versions/32023` (Tahoe's own compiler) to `Versions/31001` (where MetalOld and MTLCompilerService look), with the `libLLVM` wrapper kept so Tahoe's AIR 2.8 libraries still convert, and puts it in place of the 13.x files in `13.6-25` and `13.2.1-25`. It adds about 100 MB, and `libmetal_boundscheck.a` stays the 13.x one because `14.2 Beta 1` has none.

## 7. Haswell's framebuffer: Linux's RC6 thresholds

`RCxControl` in `AppleIntelFramebufferAzul.kext/Contents/Info.plist` (`Universal-Binaries/12.5`, `12.5-23` and `12.5-23.4`) gets Linux's Haswell RC6 values, `GEN6_RC6_THRESHOLD` 50000 in a `GEN6_RC_EVALUATION_INTERVAL` of 125000, instead of the Monterey framebuffer's 520 in 26000. With the eager values the Iris Pro 5200 hung on its way out of RC6 under Safari's WebGL video uploads (the gen7 hang Linux works around in 2c550183); with these the video pages run without a GPU reset, and an idle GPU still enters RC6. OCLP copies this `Info.plist` as it is apart from `OSBundleRequired`.
